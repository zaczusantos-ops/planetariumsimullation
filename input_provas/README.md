# Pasta de Entrada de Provas / Questões da IOAA

Coloque aqui os arquivos de texto, PDFs ou enunciados que deseja simular.

### Formatos suportados:
* Arquivos `.txt`, `.md`, `.pdf` com o enunciado completo.
* Notas manuscritas ou imagens com o problema transcrito.

### Exemplo de Prompt para o Antigravity:
> "Resolva a questão descrita em `input_provas/questao_1.txt` e gere a simulação VR 360° em `output_videos/`."
